# 停止・超低速車の追い越しと車間制限の引継ぎ

現在位置の横方向分離を待つ代わりに、同じ制御周期・車線・経路・V2X snapshot の正確な本番MPC予測で移行経路を検証する。対象速度の上限は既存 strict_shadow_commit_creep_max_target_speed（1.5 m/s）を共用する。

現在車体から予測の先頭、各予測点間を連続的に検証する。区間の並進・回転と相手の移動を包む余裕を加え、位置観測からの経過時間も反映する。全観測車について速度推定と新鮮な姿勢・位置が必要。Center経路予測にも衝突がなく、予測末尾で対象への横余裕または通過完了が確保される場合だけ、対象IDごとに車間制限を解除する。短い安全な予測だけでは解除しない。未知方向の車体を消さず円形で検証する。

MPC失敗・緩和解・境界崩壊・予測fallback・車線不一致・復旧/後退中は許可しない。判定は毎周期作り直し、旧承認を持ち越さない。

解除対象に限りACC、低速対象への速度同調、EmergencyBrakeの車間制限を外す。他車や後段のParallelSafety・復旧等の制限は残す。移動中は通常速度制御を継続する。停止からは既存Hybridの0.6 m/s前進処理に接続し、最終速度上限を尊重する。予測が衝突を含む/進行しない場合に未検証の前進を作る変更ではない。

診断: `[SlowPassSpacingRelease] lane=L2, vehicles=['d2', 'd3']`。

検証: 518 tests passed、Python compile、git diff --check。追加テストは連続区間衝突、2台の移行前解除、未知後方速度、古いsnapshot、境界崩壊・緩和、短い予測、他車停止制限の順序独立性を含む。2台の単体fixture（車線幅・Center予測はstub）の60回計測は中央値2.35 ms、最大2.50 ms。ROS周期全体や実車走行の計測ではない。AWSIM走行は未実施。
