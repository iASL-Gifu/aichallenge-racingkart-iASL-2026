# unknownによる不要な追越し解除の修正

対象: 現在のaichallenge_submit。原因調査の1・2を修正。

## 変更

- V2Xの同時刻・同位置の再送はサンプル更新せず、速度推定・元のサンプル対・ゼロ補間期限を維持する。同時刻で位置が違う場合、時刻巻戻り、位置飛び、過大速度は従来どおり無効化する。再送は情報鮮度を延長するものではない。
- 対象の速度推定無効だけでtarget_geometry_unknownにしない。現在位置が有効なら車体範囲を評価する。速度から向きを推定できない場合は対象の外接円と自車の矩形で保守的に評価し、任意の対象向きを含む範囲で重なりを確認する。遠くにいる対象の一時的な速度欠落を、道路幅喪失・左右候補禁止へ変換しない。
- 対象以外の車は、接近可能範囲と選択レーンとの関係を確認してからunknownを解除条件に入れる。範囲は車体長・目標車間に、予測/反応時間の接近距離と相対速度による制動距離を加える。速度不明ならtrackerの安全速度上限を使用する。固定距離の後方窓へ縮める変更ではない。
- 明示的にfront/side/rear競合と判定された車は距離による除外を行わない。特に予測上の横侵入は即時危険のまま。
- 一度この対象・レーンに関連すると判定した車は、位置が欠落してもunknownとして残す。別レーン・十分遠方と確認できれば関連性を解消する。対象/レーンの変更や検証・Hybridの破棄では関連性の記憶をリセットする。
- 位置不明で、過去にも今回にも選択レーンとの関連性を確認できていない車だけを根拠として、新たなレーン解除は起こさない。近い後方車の速度不明や近傍の車線不明は解除側に残す。
- OvertakeLaneHoldログにunknown_detailsを追加し、位置・車線・距離・速度のどれが不明だったか分かるようにした。

Oldのようにunknownを一律無視する戻し方はしていない。Oldとの差分調査で挙がった速度上乗せ、微速脱出、Hybrid完了条件、地理的規制は今回の対象外。

`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONPYCACHEPREFIX=/tmp/submit_unknown_pycache python3 -m pytest -q -p no:cacheprovider aichallenge_submit/multi_purpose_mpc_ros/test`

376 passed（13件追加、2つの既存パラメータ/前提を変更）。git diff --check通過。

- 正常な4m/s推定後の同一V2X再送で、速度ゼロ化や対象由来のunknown解除が起きない。
- 再送を繰り返しても実停止の0.20秒補間期限を延長せず、snapshotとも独立。
- 速度不明でも離れた対象の車体非重複を評価でき、近傍・接触では保守的に重なりを判定。
- 遠方の速度/車線不明や無関係な位置欠落は解除しない。
- 近い後方車、直前まで関連した車の位置欠落、固定窓外の高速後方車、明示的な予測横侵入は引き続き危険/unknownとなる。
