# 4台走行デッドロック候補の修正（2026-09-06）

現在のSubmitの選択・Abort解除・停止車群・後退計画へ統合した。

1. `_select_follow_escape_lane()`でL2も採用する。L2の禁止判定でL1へ戻された場合にも、残るL0候補を検査する。採用前に幅、L0禁止区間、前後の動的交通・速度不明を確認する。実際の前進は既存の連続した有効解・進路検証に従う。
2. `_release_stationary_parallel_abort()`の「群に前方車が必要」という条件を削除。横または少し後ろの停止対象だけでも、安全な停止車群の候補があればAbortと並走タイマーを解除し、通常の進路再評価へ戻る。直接の速度引上げや新レーンの確定は行わない。幅不足、車体重複、危険／不明な交通、禁止区間、回復中の拒否条件を維持する。
3. `_stationary_lane_group()`を通過可能な手前の区間へ限定する。次の通過不能車までの距離から、車体長、車間余裕、反応距離、制動距離、および直前の対象を通過し切る余裕を引き、範囲内の対象だけを群へ残す。速度は現在速度とHybrid脱出速度の大きい方で評価する。区間外の車はV2X・MPC・交通判定・EmergencyBrakeに残り、低速脱出の対象別例外を受けない。近い障害や速度上昇に伴って群を縮小／解除する。
4. `_reverse_vehicle_clear_distance()`で、後方車を含めた後退可能距離を算出。相手の向きに依存しない車体外接半径、余裕、後退の制動距離、相手の接近速度と反応時間を考慮する。静的な壁までの距離と車両までの可動距離の小さい方を計画へ使う。近傍車の速度不明、位置不明、最小可動距離未満では拒否する。

後退は`vehicle_bounded`モードとして既存の距離管理へ渡す。開始待ちでも計画した短い距離を使用し、従来の長い確認距離による不要な取消を防ぐ。後退中は残距離に対して同じ車体・速度判定を再実行し、後方車が接近したら既存の停止・DRIVE復帰へ移る。前進解が得られた場合の既存の早期後退終了も維持する。
