# 見た目と車体重なり判定の不一致（2026-09-06）

今回は調査のみ。制動条件・車体寸法・設定は変更していない。

## 確認できた事実

現在版とOldの以下3メソッドはAST比較で完全一致する。
- `_oriented_vehicle_rectangles_overlap()`
- `_current_center_envelopes_are_separated()`
- `get_ego_pose()`

SATは世界座標上で、受け取った位置を中心とする全長2.0m・全幅1.5mの矩形同士を比較する。現在車体判定へのmargin引数は省略され0.0。したがって今回のrect_overlap=Trueは、予測用margin=0.15やOUTER_COURSE_MARGINを直接加えた結果ではない。

相手の向きは速度が0.15m/sより大きければ速度方向、それ以下なら最寄りCenter Waypointの接線方向。V2XVehiclePosition.msgには向きがなく、positionとcovarianceしかない。停止時に実際の車体姿勢を測定しているわけではない。Oldも同じ。

`get_ego_pose()`はGNSS位置があればそれを使い、yawはOdometryから使用する。V2X側は受信positionを直接使う。車体中心への変換や、これらの観測時刻を揃える処理はこの経路にない。どの位置基準でAWSIMがV2Xを配信しているかは、ローカルのメッセージ定義だけでは確定できない。

## 車体寸法・原点

`racing_kart_description/config/vehicle_info.param.yaml`から:
- 車体長: wheel_base 1.087 + front_overhang 0.467 + rear_overhang 0.510 = 2.064m
- 幅: tread 1.12 + left 0.165 + right 0.165 = 1.450m
- 後輪軸位置を原点とすれば前端+1.554m、後端-0.510m、車体中心は前方+0.522m

URDFの表示meshにもbase_linkから前方0.5mのオフセットがある。これは原点確認の根拠になるが、AWSIMの実コライダーやV2Xの配信原点まで証明するものではない。

現在の対称矩形は前後±1.0m。配信位置が後輪軸であれば、後端を実設定より0.49m後方、前端を0.554m後方に誤配置する。両車が同じ原点・同じ向きなら共通の中心補正は相対位置で相殺するため、オフセットだけで今回の誤判定を断定しない。コーナーで異なる向き、または配信原点が異なる場合に効く。

幅1.50→1.45の変更だけでは、同一姿勢での2台分の横方向差は合計0.05m。ログの-0.62mの横車体間隔を、それだけで説明するのは難しい。

## 方向仮定の影響の確認

実際のSAT関数へ、説明用にego=(0,0), yaw=0、target=(1.84,1.05)を入力すると、target yaw=0ではTrue、yaw=-45度ではFalseとなる。向きの置換だけで判定が反転し得ることを確認した。

この例は今回ログの配置の復元ではない。ログのCenter弧長1.84mとlateral1.05mはそのまま世界座標差ではなく、実際のd2 yawも記録されていない。今回の原因確定にはその入力が必要。

## 修正方針

1. 衝突用の車体姿勢取得を共通化する。map座標、車体中心、yaw、観測時刻、yawの取得元・有効性を一組で返す。
2. 可能ならAWSIM/V2Xに実車yawを追加する。位置しか使えない構成では、有効な移動中に得た方向を速度とは別に保存し、停止時にCenter接線へ切り替えない。位置飛び・ID消失・不連続観測で無効化する。後退時の速度方向と車体方向の180度差も、前後オフセットには影響するので考慮する。
3. 初回から停止していて実方向が不明なら、Center接線を確定姿勢として扱わない。方向不明を明示し、不確実性付きの障害物判定／安全な再計画へ渡す。方向不明だから衝突なしとする変更はしない。
4. GNSS/V2Xそれぞれの原点を確認して車体中心へ変換する。後輪軸原点なら前方0.522m補正が候補。未確認のまま両方へ一律追加しない。
5. 現在SAT、committed lane hold、Center経路予測、MPC予測照合、停止車群の非重複判定を同じ車体姿勢・寸法へ統一する。現在判定だけ修正しても別系統の誤停止が残る。
6. 診断ログとRVizに、実際にSATへ渡した2台の矩形を出す。位置・中心変換量・yaw・yaw取得元・観測経過・frameを添える。見た目の車体と矩形が一致するか確認する。Centerのarc_gap/lateral_gapは経路上の余裕として別記し、実矩形の交差と混同しない。

Oldからこの判定を移しても改善しない。先に入力する姿勢と原点を正す。誤重なりを理由にEmergencyBrakeを無効化したり、幅・全長を恣意的に縮めたりしない。
