# 空きレーンがあるのに停止する状態の修正と追加調査

対象ログ: 83df4765-4d7f-4a25-aed4-8025d8c31515/pasted-text.txt。L2は1.728/1.600 m、対象余裕2.878/1.825 mで通行可能。1788702485.630ではtarget_geometry_unknownを理由に全幅復旧へ解除。復旧はL0の方向誤差11.1〜11.3度/10度で待機。一方、停止脱出はL2を要求するがrequest=2/applied=None/full_width_recoveryで試行できず、未適用の試行を失敗扱いにして後退へ移った。

## 今回修正した点

1. 対象形状の一時的な不明は、確認時間（既存0.40秒）内は車線を保持し前進を止める。回復すれば同じ車線を継続する。不明が継続すれば既存の安全復旧へ移す。道路幅喪失・実重なり・別車両の危険は即時処理。形状、位置の有効性、時刻、経路距離、passageの有無をログに出し、不明の入力原因を追えるようにした。ログだけでは元の不明原因は確定できない。
2. 停止脱出で選ばれた外側レーンについて、停止/超低速、通行幅、交通、全観測車の現在非重複・速度有効性を確認してからPrepassが試行の所有権を渡す。L0の姿勢待ちとL2の試行を同時に走らせない。ソルバ復旧、後退、ParallelAbortなどは優先を維持する。引継ぎは移動許可ではない。
3. レーンが未適用の試行は候補の失敗・後退判断へ数えない。適用を待つ診断を出す。
4. 停止脱出の外側レーン試行には、MPC計算用の低速参照を与える。実出力は従来通り安全な前進解の連続確認までゼロ。外側試行の衝突証明には、前回追加した全観測車・連続区間の確認を使用する。
5. MPCの既存current_predictionはupdate_predictionのrange(2,N)で先頭2点を省いた表示用予測だった。前回追加した接続距離1 m判定は、その省略を不連続と誤解し得た。新たに同じ成功解のrange(0,N)を保持し、連続衝突確認ではその近傍点を使う。旧解の近傍点は参照同一性で拒否する。
6. SlowPassSpacingHoldに、復旧状態、予測不連続、観測不明、連続区間衝突、Center予測衝突などの不成立理由を記録する。

## 追加で残る原因候補（未修正）

### 優先度 高: 空間予測の点番号を時刻とみなしている

mpc_controllerの_v2x_t_samplesはN/control_rateから生成される。一方MPC.update_predictionは経路上のWaypointに対応する空間予測。_center_path_collision_prediction、_prediction_collision_with_vehicle、連続区間確認がこの時刻配列を使用する。停止中でも先の空間位置に小さなTTCが割り当てられるため、ログの0.21秒を実際の到達時間とは解釈できない。移動車との交差時刻や予測対象位置もずれる。解の速度/経路距離から到達時刻を作り、停止で未到達になる点を明示する必要がある。衝突の有無自体が誤りとはログだけでは断定できない。

### 優先度 高: 動的境界を消す比較用設定が有効

config.yamlのunsafe_static_fallback_on_narrow=true。reference_path.update_path_constraintsは動的障害物で狭くなった区間を静的境界に戻せる。このためMPCがsolvedでも後段の車体衝突確認が止める状況を作り得る。通常の走行評価では動的境界と衝突確認を整合させる必要がある。今回は既存の比較用設定を変更していない。

### 優先度 高: 幅判定と車体判定の意味が異なる

PhysicalPassageDiagnosticは必要幅1.6 mを使用する。共通車体判定では現在の原点不確実性込みで自車約1.994 m、他車約2.014 m。また道路境界/障害物グリッドと回転車体の確認が別で、passable=Trueは移行経路の全区間非衝突の証明ではない。単に1.6 mを2 mへ変更すると過剰停止を増やすため、原点の確認と境界の車体中心化を含めて整理が必要。

### 優先度 中: Hybrid完了前の停滞監視

_update_outer_lane_progress_stateは横移動誤差0.45 m以内になるまで進捗タイマーをリセットする。横移動前の停止にはこの監視が働かず、別のFollowDeadlock検出に依存する。今回その脱出経路を修正したが、追従/緊急停止以外の速度制限による移行中の停滞も監視すべき。

### 優先度 中: 短い予測と遠方の未知車両

SlowPassの証明は全観測車の有効速度を要求し、予測末尾で横分離または通過を要求する。遠方車の初回観測や短いホライズンでも解除しない。安全上必要な保守性を保ちつつ、到達可能領域と制動距離で関係する車両/区間を限定する余地がある。

### 優先度 中: 後退の計画と実行時の静的安全判定

ログでは5.75 mの後退計画が作られた直後、0.13 mでstatic_path_blockedとなった。直進距離余裕と実際の車体/姿勢を使う走行判定が一致しているか再検証が必要。今回、レーン未適用を通行不能と誤認して後退する経路は修正したが、後退幾何そのものは変更していない。

## 検証範囲

ROSを必要としない実コントローラの抽出メソッドとMPC試験を使用。AWSIM走行は未実施。実機で停止が全て解消したと保証するものではない。診断ログはFollowProbePrepassHandoff、FollowProbeDeferred、SlowPassSpacingHold、OvertakeLaneHoldを確認する。
