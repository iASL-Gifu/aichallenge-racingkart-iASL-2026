# multi_purpose_mpc_ros

## setup
```
cd /aichallenge/workspace/src/aichallenge_submit/
git clone git@github.com:Roborovsky-Racers/multi_purpose_mpc_ros.git
cd multi_purpose_mpc_ros
git clone git@github.com:Roborovsky-Racers/Multi-Purpose-MPC.git -b aic-2024
```

## build
```
cd /aichallenge/workspace/
cb
```

- virtual env will be created to ${ROS_WS}/install/multi_purpose_mpc_ros/.venv when build time

## run
### sample simple publisher node
```
ros2 run multi_purpose_mpc_ros run.bash
```

### Multi-Purpose-MPC simulation
```
ros2 run multi_purpose_mpc_ros simulation.bash
```

### both
```
ros2 launch multi_purpose_mpc_ros test.launch.xml
```

### スタック時の低速復帰

`stuck_recovery.straight_reentry_enabled` は一般スタックの復帰を有効にします
（設定名は既存互換）。有効なGNSS位置とodometry方位を確認し、GNSSでほぼ停止した状態が
`stuck_time_threshold` 秒続き、速度報告でも停止を確認したら開始します。境界内外・境界超過量は判定に使いません。
位置情報の有効性と停止観測窓には確認時点の現在時刻を使います。
AWSIMの`Grounded`・`Ready`などの状態名には依存しません。
意図的な追従停止・制御無効は復帰を開始せず、情報無効時は復帰中の動作を止めます。

復帰速度は前進・後退とも既定1.0 m/s（実装上限も1.0 m/s）です。他車予測の時間計算にも同じ速度を使います。
前方約3.5 mのWPを目標として、左操舵・直進・右操舵をそれぞれ2 m先まで予測します。
静的地図と他車予測の衝突検査を通った前進候補を、壁との重なりの減少量、WP方向への姿勢改善量、WPへの接近量の順で比較します。
重なりは全候補で同じ余白を使った接触セルの食い込み量合計、姿勢は現在位置から目標WPへの固定方位に対する角度誤差で評価します。
`StuckMotionSelect`の`wall_reduction`は地図格子上の評価値（移動距離ではありません）、`heading_improvement`は角度誤差の減少量です。
前進が使えない場合だけ直線後退を検査します。後退に境界の改善条件はありません。
2 m後退の途中で壁との重なり改善条件を失う場合、または新しい壁への接触を予測する場合は、5 cm刻みで予測を短くし、
重なりが減るか、壁に接触しない最長の区間を選びます（最短10 cm）。各区間で静的地図・他車の検査をやり直します。
短い後退では0.5秒の応答時間、1 m/s²の減速、5 cmの余裕を確保する速度上限を使います。
現在速度からの停止距離を確保できない区間は選びません。毎周期再評価し、
`StuckMotionReversePrefix`に選択距離と速度上限を記録します。
前後とも使えない場合は`StuckMotionBlocked`に候補ごとの理由を出して停止し、毎周期再評価します。
前進復帰では、初期の壁との重なりが予測途中で増えず、終端で減る動きを許可します。
前進では接触セルが隣接セルへ移ること自体は許容しますが、総食い込み量・最大食い込み量の増加、
離れた新しい接触箇所、離脱後の再接触、他車への接触、地図外・位置方位無効は拒否します。
壁から離れると確認された前進は、一時的にWPから遠ざかる場合も許可します。

速度は最大1.0 m/sです。前後切り替えは停止してギアを確認し、停止中の操舵変更は準備時間を確保します。
前進中の操舵はレート制限して更新します。安全な前進候補・実前進・正常MPCに加え、
ステアリング代替制御が解除され、通常制御の最終指令が前進を要求する状態が
`straight_reentry_success_cycles`回続いたら停止観測履歴を消して通常制御へ戻します。
引き継ぎ周期は通常制御の指令をそのまま使い、速度ゼロ・ブレーキを挟みません。
動き始めた時点でも停止観測をリセットし、遅延GNSSによる直後の再突入を防ぎます。
追越し・前方車回避から明示的に要求された後退は、既存の距離管理処理を使用します。

固定3候補が成立しなくても、通常の前進指令と新しい正確なMPC予測があり、
MPCが生成した位置・Yaw角の予測経路に対する共通の物理チェック（壁・他車、初期重なりの改善条件）が
連続成功した場合はDRIVEへ移行できます。この経路では実際の前進開始を解除条件にしません。
後退中は先に制動し、DRIVE確認後に通常指令を引き継ぎます。確認中に条件を失えば移行を取り消します。

前進復帰では固定操舵による別の予測を作らず、正常解として採用したMPC状態列を使います。
現在位置から予測開始点への接続も含め、位置間隔5 cm以下・角度間隔0.05 rad以下に補間して検査します。
他車予測の時刻は引き継ぐ前進指令速度で計算します。拒否理由は`MPCRecoveryPathBlocked`に記録します。

通常制御へのフォールバック解除とスタック復帰解除は、`_mpc_prediction_path_is_clear`で
同じMPC位置・Yaw列を検査します。Pure Pursuit自体には従来の固定操舵予測を使います。
スタック復帰は正確なMPC解と前進進捗を追加条件とし、固定前進候補が動いているだけでは解除しません。
通常制御の近似解には既存の予測接続・交通確認も維持します。

後退の壁重なり評価は、予測開始時を基準に途中の最大食い込み増加を
`stuck_recovery.reverse_overlap_allowance`（既定0.03 m）まで許容します。
終端では食い込み量合計が初期より減り、最大食い込みも初期以下であることを必須にします。
上限は各点の直前値ではなく初期値から計算し、予測内で増加を累積許容しません。
0にすると従来の単調改善条件に戻ります。前進・MPC経路の条件は変更しません。
新しい壁接触、離脱後の再接触、他車接触、無効な位置情報は引き続き拒否します。
この変更は後退候補の選択に限り、停止指令と速度報告の不一致を解消するものではありません。

方位誤差が45度を超える場合は、目標WPの参照経路方位へ2度以上改善できる前進も採用します。
一時的にWPから遠ざかっても、壁・他車の安全検査を通れば旋回できます。
この間は同じ旋回方向の安全で改善する候補を優先し、失われれば反対側も再評価します。
MPCの連続確認中も、DRIVEで既に前進中・操舵準備済み・安全な前進候補ありなら
低速前進を維持します。停止中や後退中にはこの確認待ちで前進を開始しません。
通常制御への引き継ぎ時は加速度フィルタの負の履歴を0に戻し、制動を持ち越しません。
後段の追従・非常制動等の安全制限は引き続き適用します。


車体基準は `collision_geometry.ego_position_origin: rear_axle` とする。
AWSIMのGNSS・IMUはbase_linkと同位置・同姿勢なので、simulation用TFをゼロに揃える。
MPCの状態とGNSS poseは後軸中心のまま、追加検査でのみYaw方向へ0.522 m移して車体中心に変換する。
車体寸法はvehicle_info.param.yamlに合わせて全長2.064 m・幅1.45 m。
MPCの壁制約も後軸から前端1.554 m／後端0.510 mの非対称な張り出しを使う。
明示された位置基準はV2Xによる推定alignmentで上書きしない。
位置基準未確定の余白は追加しないが、地図のコース余白・外周guard・サンプル間の掃引余白は維持する。
MPCは線形化した壁制約、追加検査は回転矩形と占有地図を使うため、判定方式そのものは異なる。
センサーTFの反映には再ビルドとlaunchの再起動が必要。

根拠: [AWSIMセンサー仕様](https://automotiveaichallenge.github.io/aichallenge-documentation-racingkart/specifications/simulator.html)、
[Autowareのbase_linkと車両寸法](https://tier4.github.io/autoware-documentation/tier4-main/design/autoware-interfaces/components/vehicle-dimensions/)。


前進の実績監視はMPCの成功や復帰完了をまたいで保持する。
新鮮な位置観測があり、DRIVEで前進指令が出ている間、1.5秒間で15 cmの実移動が
得られない場合、または壁との重なりがある状態で重なり評価値が5%以上
（最低0.01）改善しない場合は前進を保留する。
`RecoveryForwardNoProgress` に理由を出し、MPCへの引き継ぎを抑止して安全な後退を評価する。
失敗時の位置・姿勢・重なりを記録し、次のいずれかで前進保留を解除して再評価する。
後退で50 cm以上移動、別の前進で15 cm以上移動して重なりが5%以上（最低0.01）改善、
または重なりが悪化せず位置が50 cm以上／姿勢が10度以上変化した場合。
解除時は同じ失敗姿勢に対する候補除外も解除する。MPC経路の安全検査と連続成功確認は
解除後も必須で、同じ姿勢のままMPCが解けただけでは解除しない。
`RecoveryForwardReevaluate` に再評価開始を出力する。
後退も安全検査に通らなければ停止を維持する。意図的な停止・情報鮮度切れは監視時間に含めない。

左右に操舵する前進復帰は、単調な重なり改善の検査に失敗した場合のみ、最大食い込みの一時増加を `forward_turn_overlap_allowance`（既定3 cm）まで許可して再検査する。終端で重なり総量が減り、最大食い込みが初期値以下で、WP方向への方位誤差が2度を超えて改善することが条件。新しい壁との接触、他車衝突、情報不足は緩和しない。直進・通常MPCは従来の検査を維持し、実績監視による前進保留も維持する。

MPC復帰の連続成功確認中も、安全な前進候補があれば共通のギア・操舵準備処理を実行する。DRIVE確認と操舵待機が完了すれば停止状態から低速前進を開始し、確認終了まで速度ゼロに固定しない。上限は復帰速度・候補の安全速度・MPC指令速度の最小値。後退中や安全な前進候補がない場合は発進しない。

通常復帰が全候補を拒否した際は、前進左右・直進・直線後退の0.5/1.0/1.5/2.0 m区間を比較する。初期接触があり、食い込み増加3 cm以内・終端の重なり減少を満たす候補の中で重なり減少、姿勢改善、WP接近の順に選び、最大0.5 m/sで実行する。同じ壁の接触移動は占有セルを経由した3セル以内の局所接続に限って許可する。通常MPCの判定は緩和しない。復帰中の前進・後退とも1.5秒改善しない候補は失敗姿勢が変わるまで除外する（50 cm移動または10度旋回、重なり非悪化）。他車、情報不足、全候補の悪化を無視する強制走行は行わない。

スタック監視の初回有効化にはAWSIM状態を使わず、新鮮なGNSSで30 cm以上の位置変化と実速度0.15 m/s超を確認する。確認前は通常前進制御を維持し、不動を理由に復帰やR要求を開始しない。配置ジャンプ・鮮度切れ・同一観測の反復は走行開始の証拠にしない。一度走行確認後は、停止しても復帰監視を維持する。初期位置から全く動けない場合と開始待ちはこの情報だけでは区別できないため、初回走行前のスタック復帰は行わない。


復帰の前進にも短区間評価を適用する。全区間が壁で拒否された場合、予測距離の
75%・50%・25%・12.5%と現在速度で必要な最短停止距離を長い順に再検査する。
各区間で操舵の立ち上がりを再予測し、地図と他車の掃引検査を通したものだけを使う。
速度上限は反応0.5秒・減速度1 m/s²・余白5 cmを区間内に確保する値と復帰設定速度の最小値。
現在速度から停止できない長さは採用しない。他車・情報不足の拒否は短区間化で緩和しない。

左右・直進の候補角は最終目標として保持し、予測では直前の操舵指令から操舵レート上限に
従って変化させる。停止時も同じ予測を使い、実行時のギア・操舵準備確認は維持する。
走行中の指令は1周期分の操舵レートで制限する。後退候補は引き続き直進のみ。

選択した動作は準備完了予定から1.5秒まで観測のため保持し、その後は15 cm以上の実移動と
既存の重なり改善条件を満たしたときだけ保持を延長する。保持中も現在位置から候補を
再生成・安全検査し、安全性の喪失や実績監視による除外があれば直ちに再選択する。
後退で予測距離分（既定2 m）を実移動したら前進候補も再比較し、後退を無期限に保持しない。
MPCへの有効な前進引き継ぎは保持より優先する。診断は `StuckMotionValidatedPath` に
`retained:` と安全速度を出力する。AWSIM状態トピックによる判定は追加しない。

直進保持中も左右の前進を安全検査し、直進より方位誤差の改善が5度を超えて大きく、
重なり減少量も直進に劣らない旋回があれば `turn_improves_held_straight` で選び直す。
僅差や不安全な旋回では保持を解除しない。
前進中に壁で候補を失って後退・停止へ移る場合は、失敗位置・姿勢を
`RecoveryWallReturn` として最大16地点記憶する。操舵方向そのものは除外しない。
予測経路が失敗地点の30 cm以内へ、失敗時と15度未満の姿勢差で再進入する場合を
`remembered_wall_return_at_step` で拒否する。後退後に同じ操舵でも別の経路を通る場合や、
姿勢を変えて通る場合は地図・他車の安全検査を通せば選択できる。
初期位置が記憶範囲内なら、その範囲から離れる経路は許可し、離れた後の再進入を拒否する。
判定は保持候補・短区間・最終手段の前進と、MPC引き継ぎ経路に適用する。
後退やMPC再評価用の保留解除だけでは履歴を消さない。壁・他車の検査は従来どおり維持する。


復帰中の操舵角は送信指令への瞬時到達を仮定せず、直前の送信角・経過時間・操舵レートで
推定する。実角の計測ではなく推定である。停止中（既存の0.1 m/s閾値以下）は車体を止めて
操舵準備するため、候補の移動経路は目標操舵へ到達した状態から検査する。
走行中は推定途中角から目標角へ変化する経路を検査する。これにより停止中に指令角が
変わっただけで予測経路が交互に変化することを防ぐ。準備期限は推定角からの到達時間に
既存の0.25秒を加えて設定し、同じ安全な候補を保持する間は更新しない。
地図・他車・失敗地点への再進入の拒否は引き続き優先する。
